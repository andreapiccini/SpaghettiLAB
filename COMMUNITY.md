# Community scope

SpaghettiLAB Community exists to make the platform easy to learn, inspect,
modify, extend, and use for real prototypes.

Community contributions should improve at least one of these areas:

- reference hardware and Module compatibility;
- firmware capabilities and portability;
- local configuration and visualization tools;
- documented protocols, schemas, and SDKs;
- examples, tests, and learning material.

The Community distribution does not intentionally degrade local functionality.
Its boundary is operational: it does not include private manufacturing data,
production credentials, signing infrastructure, managed fleet services, or a
commercial support commitment.

Never commit credentials, production keys, customer data, or private
certificates. Security reports must follow the applicable component security
policy.
