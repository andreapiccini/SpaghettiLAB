# Settings — Visual

[← UX](../../README.md) · [UI](ui-behavior.md) · [Host](host-behavior.md)

Lista raggruppata, nessun color picker (quello è Appearance).

1. **Account** — nome, email, ruolo; CTA Esci.
2. **Tab** (solo `host.user.manage`) — Display | Utenti (selettore a goccia, vetro).
3. **Display** — Normale / Kiosk / Compatto (selettore a goccia, vetro, senza bordo nero).
4. **Host** — nome + indirizzo in sola lettura.
5. **Scorciatoie** — Aspetto, Marketplace (se in scope).
6. **Info** — versione; voce automazioni informativa (no editor).
7. **Utenti** — elenco persone (`type.body` + `type.caption` email/ruolo/stato), CTA Invita (`color.accent`), Revoca per gli altri. Sessioni attive in sola lettura. Link “Richiedi supporto SpaghettiLAB”.
