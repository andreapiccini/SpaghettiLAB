# Settings — Visual

[← UX](../../README.md) · [UI](ui-behavior.md) · [Host](host-behavior.md)

Lista raggruppata, nessun color picker (quello è Appearance).

1. **Account** — nome, email, ruolo; CTA Esci.
2. **Display** — Normale / Kiosk / Compatto (selettore a goccia, vetro, senza bordo nero).
3. **Host** — nome + indirizzo in sola lettura.
4. **Scorciatoie** — Aspetto, Marketplace (se in scope).
5. **Info** — versione; voce automazioni informativa (no editor).
