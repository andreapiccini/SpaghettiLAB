# Licensing Policy V1

> Historical policy, superseded by `licensing-policy-v2`. It records the licensing
> map before the copyleft transition and is not the current working-tree policy.

This contract makes the current multi-license layout machine-readable. It does not
invent restrictions or replace the licence texts.

Commercial use is allowed under each applicable open licence. Commercial value is
created through controlled Production implementations, qualification, managed
services, certification work and support—not by claiming that Community forbids
companies from using already-licensed code.

Contributions use DCO 1.1 sign-off. DCO records provenance but does not assign
copyright or automatically enable proprietary relicensing. A future licensing change
requires a separate rights and legal review.
