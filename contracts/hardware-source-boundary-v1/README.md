# Hardware source boundary V1

Community owns editable KiCad sources for Backbone, Core and the NFC Tag module.
Their schematic symbols and placed PCB footprints are embedded in the project files;
opening these designs does not require Production.

Production may maintain controlled hardware variants, approved BOMs, manufacturing
outputs and certification evidence. Every private variant must identify the exact
Community commit it was reviewed against. It is not silently synchronized with the
public board.

External 3D models are optional. Models or global workstation libraries with
unverified redistribution terms are not copied merely to remove a 3D-view warning.
Generated BOM, Gerber, drill, placement, netlist and fabrication packages are not
tracked in Community.
