# Firmware licensing policy

Original SpaghettiLAB firmware in this directory is licensed under
GPL-3.0-or-later. The accompanying `LICENSE` contains GPL version 3.

Language-neutral protocol definitions in the repository-level `contracts/` directory
remain Apache-2.0 so independent compatible implementations can be created. Bundled
third-party code retains its own licence and notices.

The exact Git transition commit will be recorded when the new history is finalized.
Earlier Apache-2.0 revisions retain their previously granted permissions.
