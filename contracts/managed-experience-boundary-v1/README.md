# Managed experience boundary V1

Community includes a working local Node-RED environment and a complete Dashboard
renderer with editable appearance and local Visual Packs. Neither requires a paid
controller, hosted branding service or organization account.

Production may add the operational services that become valuable at customer scale:
multi-site Node-RED lifecycle management, monitoring, scheduled encrypted backup,
controlled restore, customer-pack distribution, hosted assets and managed rollout.

Backup payloads, credentials, customer logos and customer-specific assets are runtime
data. They must be stored in approved external systems and never committed to either
repository. Production code contains contracts and adapters, not customer data.
