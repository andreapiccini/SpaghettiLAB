# Licensing Policy V2

V2 introduces the new copyleft Community generation: firmware under GPLv3-or-later,
public applications/services under AGPLv3-or-later, permissive interoperability
contracts and selected SDKs under Apache-2.0, open hardware under CERN-OHL-S-2.0 and
documentation under CC-BY-4.0.

The repository's `clean-history-root` commit marks this transition. Old
Apache-licensed revisions keep their grants. Third-party dependencies keep their own
terms.

External code contributions to GPL/AGPL commercial-overlap areas are temporarily not
merged. This avoids relying on DCO for rights it does not provide.
